# Paws & Claws Academy

A modern, responsive landing page for **Paws & Claws Academy** — professional pet and home care in Sydney.

> **Happy pets. Happy home. Happy you.**

## Overview

A single-page marketing site designed to feel professional, trustworthy, and welcoming. It highlights the two core service lines — **Pet Care** and **Home Care** — and guides visitors toward booking a visit.

## Sections

- **Hero** — headline, subheadline, and a "Book Your Visits Today" call to action.
- **Services** — Pet Care (feeding, litter cleaning, poo collection, and more) and Home Care (home checks, mail collection, plant watering).
- **Why Us** — trust signals: insured, daily photo updates, genuine care, local to Sydney.
- **How It Works** — a simple three-step process.
- **Contact / Booking** — a booking request form.
- **Footer** — with the tagline *Happy pets. Happy home. Happy you.*

## Tech Stack

- **HTML5**
- **Tailwind CSS** (via CDN) for styling
- **Vanilla JavaScript** for the mobile menu, footer year, and scroll reveals
- Custom `styles.css` for a few supporting styles

## Running Locally

No build step is required. Just open `index.html` in your browser, or serve the folder:

```bash
# Python
python3 -m http.server 8000
# then visit http://localhost:8000
```
