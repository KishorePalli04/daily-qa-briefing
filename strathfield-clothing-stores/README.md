## Method and caveats

- Findings come from web searches across the Strathfield Plaza directory, Word of Mouth, Wheree, Yelp, dlook, Facebook/Instagram, and business-award listings. Several directory sites blocked automated access, so store discovery relied on search snippets rather than full directory crawls.
- "No website" means no store-operated website surfaced across multiple targeted searches; a site that exists but is effectively invisible in search would be missed (and arguably still needs help with web presence).
- The inverse limitation matters more: stores with **zero** online footprint (no directory listing, no socials) can't be found by web search at all. A walk through Strathfield Plaza and along The Boulevarde/Churchill Ave, or a Google Maps sweep of the precinct, would likely surface a few more candidates beyond these five.
